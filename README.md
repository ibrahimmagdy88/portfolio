# Ibrahim Magdy — Portfolio

Personal portfolio site (bilingual AR/EN) for Ibrahim Magdy, Senior UI/UX Designer.

Static site — no build step. Open `index.html` or serve the folder:

```bash
npx serve .
```

- `index.html` — page structure
- `styles.css` — styles
- `data.js` — projects content
- `covers.js` — project cover art
- `i18n.js` — Arabic / English strings
- `app.js` — interactions (GSAP + Lenis)
